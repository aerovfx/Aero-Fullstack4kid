### Cài đặt môi trường Python một lần / One-time Python Setup

```bash
# Tạo môi trường ảo / Create virtual environment
python -m venv drone-env
source drone-env/bin/activate  # Mac/Linux
# drone-env\Scripts\activate   # Windows

# Cài tất cả packages / Install all packages
pip install dronekit MAVProxy pymavlink \
            opencv-python numpy matplotlib \
            flask flask-socketio \
            pandas folium

# Kiểm tra / Verify
python -c "import dronekit, cv2; print('✅ OK')"
```

## ⚡ Thông Số Kỹ Thuật Nhanh / Quick Reference

### Chọn Pin LiPo / Choosing LiPo Battery

| Cell Count | Điện áp | Dùng cho |
|-----------|---------|---------|
| 2S (7.4V) | 6.0–8.4V | Drone mini <150mm |
| 3S (11.1V) | 9.0–12.6V | F450, drone tập luyện |
| 4S (14.8V) | 12.0–16.8V | 5" racing, freestyle |
| 6S (22.2V) | 18.0–25.2V | Long range, heavy lift |

### Dung Lượng vs Thời Gian Bay / Capacity vs Flight Time

| mAh | Drone size | Thời gian bay xấp xỉ |
|-----|-----------|---------------------|
| 1000–1500 | 5" racing | 4–7 phút |
| 2200–3300 | 5" long range | 8–15 phút |
| 5200–6000 | F450 | 15–25 phút |

### Công Thức Quan Trọng / Key Formulas

```
Thrust (g) = Motor_Count × Single_Motor_Max_Thrust(g)
T/W Ratio  = Total_Thrust / All_Up_Weight ≥ 2.0

KV × Voltage = RPM (không tải / no load)
Power (W)    = Voltage (V) × Current (A)
Flight_Time  = Battery_mAh × 0.8 / Average_Current_A × 60 (phút)

Ví dụ / Example:
- 4 × 920KV motors × 11.1V = 10,212 RPM (no load)
- 5200mAh, draw 15A → 5.2Ah × 0.8 / 15A × 60 ≈ 16.6 phút
```
