## 📊 Bảng Tiêu Chí / Scoring Rubric

| Tiêu chí / Criteria | Xuất sắc (4) | Tốt (3) | Đạt (2) | Chưa đạt (1) |
|---------------------|-------------|---------|---------|--------------|
| **1. Ý tưởng & Vấn đề** *Idea & Problem* | Vấn đề rõ ràng, thực tiễn, sáng tạo / Clear, practical, creative | Vấn đề rõ, có tính thực tiễn / Clear and practical | Vấn đề chung chung / Generic problem | Không rõ vấn đề / Unclear |
| **2. Thiết kế hệ thống** *System Design* | Sơ đồ khối đầy đủ, logic tốt / Complete block diagram, good logic | Sơ đồ đủ thành phần / Complete components | Thiếu một số thành phần / Missing parts | Không có sơ đồ / No diagram |
| **3. Lập trình** *Programming* | Code chạy tốt, có chú thích, cấu trúc rõ / Works, commented, structured | Code chạy, ít lỗi nhỏ / Works with minor bugs | Code chạy được một phần / Partially works | Code không chạy / Does not run |
| **4. Demo sản phẩm** *Product Demo* | Demo trơn tru, xử lý tốt tình huống bất ngờ / Smooth, handles edge cases | Demo thành công, ít lỗi / Success, few issues | Demo được một phần / Partial demo | Demo thất bại / Failed |
| **5. Thuyết trình** *Presentation* | Tự tin, rõ ràng, trả lời tốt câu hỏi / Confident, clear, handles Q&A | Rõ ràng, trả lời được / Clear, answers questions | Đọc script, lúng túng / Reads script | Không trình bày được / Cannot present |
| **6. Làm việc nhóm** *Teamwork* | Phân công đều, mọi người đóng góp / Equal distribution, all contribute | Phân công tốt, hầu hết đóng góp / Good, most contribute | Không đều, 1-2 người làm chính / Uneven | Không hợp tác / No cooperation |
| **7. Sáng tạo & Cải tiến** *Creativity* | Có tính năng mở rộng, ý tưởng độc đáo / Extra features, unique | Có cải tiến nhỏ / Minor improvements | Làm theo hướng dẫn / Follows guide | Sao chép nguyên mẫu / Copy only |
