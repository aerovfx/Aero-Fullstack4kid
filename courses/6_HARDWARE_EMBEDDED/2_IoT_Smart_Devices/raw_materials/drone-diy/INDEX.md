## 🛒 Danh Sách Linh Kiện Cần Thiết / Required Components

### Phần cứng / Hardware
| Linh kiện | Thông số gợi ý | Giá ước tính |
|-----------|--------------|-------------|
| Frame (Khung) | 250mm Racing Frame hoặc F450 | 150.000–400.000đ |
| Motors (×4) | Brushless 2205 2300KV hoặc 920KV | 400.000–800.000đ |
| ESC (×4) | 30A BLHeli_S | 300.000–600.000đ |
| Flight Controller | Pixhawk 2.4.8 hoặc Betaflight F4 | 500.000–1.500.000đ |
| Propellers (×8) | 5045 hoặc 1045 | 50.000–100.000đ |
| Battery | LiPo 3S 2200mAh / 4S 1500mAh | 200.000–400.000đ |
| Battery Charger | XT60 Charger | 200.000–350.000đ |
| RC Transmitter | FlySky FS-i6 hoặc RadioMaster | 600.000–1.200.000đ |
| RC Receiver | FlySky FS-iA6B | 150.000–250.000đ |
| FPV Camera (tùy chọn) | RunCam Robin | 300.000–500.000đ |
| **Tổng ước tính** | | **2.8–6 triệu đồng** |

### Phần mềm / Software (miễn phí)
- **Betaflight Configurator** — Cấu hình FC
- **Mission Planner** — Ground Control Station
- **QGroundControl** — GCS đa nền tảng
- **Python 3.x + DroneKit** — Lập trình tự động
- **OpenCV** — Thị giác máy tính
- **MAVProxy** — MAVLink proxy
- **Fritzing / EasyEDA** — Thiết kế mạch điện
