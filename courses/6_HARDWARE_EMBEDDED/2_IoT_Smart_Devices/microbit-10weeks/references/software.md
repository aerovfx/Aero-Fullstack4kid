# Hướng Dẫn Cài Đặt Phần Mềm Lập Trình micro:bit / Software Setup Guide

---

## 🛠️ Danh Sách Môi Trường Lập Trình & Phần Mềm

1. **Microsoft MakeCode for micro:bit (Web Editor)**:
   - Truy cập https://makecode.microbit.org/
   - Môi trường lập trình khối kéo thả (Block-based) trực quan, tự động chuyển đổi sang JavaScript và Python văn bản.
   - Hỗ trợ nạp code WebUSB trực tiếp từ trình duyệt Chrome / Edge sang board micro:bit qua cáp USB.

2. **MicroPython Web Editor & Mu Editor**:
   - Truy cập https://python.microbit.org/ để viết mã nguồn MicroPython văn bản thuần túy.
   - Hoặc cài đặt phần mềm **Mu Editor** trên máy tính: https://codewith.mu/

3. **Cài Đặt Thư Viện Mở Rộng MakeCode Extensions**:
   - Trong giao diện MakeCode, chọn `Extensions` -> Tìm kiếm:
     - `neopixel` (Điều khiển dải đèn LED RGB WS2812B)
     - `servo` (Điều khiển động cơ Servo)
     - `sonar` (Đọc cảm biến siêu âm HC-SR04)
     - `datalogger` (Ghi dữ liệu vào bộ nhớ Flash)

4. **Giả Lập Online Wokwi / MakeCode Simulator**:
   - Trình giả lập tích hợp sẵn trong MakeCode cho phép xem trước hoạt động của vi điều khiển micro:bit, nút nhấn, ma trận LED và cảm biến ngay trên màn hình.
