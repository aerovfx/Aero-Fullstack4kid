# Bài tập tuần 7: Cloud telemetry

Hoàn thiện `starter.py`, kiểm thử bằng mô phỏng trước khi kết nối phần cứng.

## Yêu cầu

- Ít nhất 3 test: bình thường, giá trị biên và lỗi cảm biến/nguồn.
- Trạng thái khởi động, mất tín hiệu hoặc dữ liệu không chắc chắn phải fail-safe.
- Ghi rõ pin, điện áp, dòng tối đa và nguồn cấp; không cấp motor từ GPIO.
- Thử nghiệm cơ khí phải tháo cánh quạt/nâng bánh khỏi mặt đất và có nút dừng.

## Chấm điểm

Logic 35%; an toàn điện/cơ 30%; kiểm thử 20%; tài liệu và log 15%.
