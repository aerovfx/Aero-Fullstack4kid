## 🛠️ Công Nghệ & Phần Mềm Sử Dụng / Software Stack

- **Ngôn ngữ**: Python 3.10+.
- **Thư viện tính toán**: NumPy, Pandas, SciPy.
- **Thư viện trực quan hóa**: Matplotlib, Seaborn.
- **Học máy**: Scikit-Learn.
- **Môi trường chạy**: Jupyter Notebook / Google Colab / VS Code.
