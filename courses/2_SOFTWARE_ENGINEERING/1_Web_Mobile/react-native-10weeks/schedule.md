# Lộ trình Lập Trình Di Động: React Native (10 Tuần)

## Tuần 1: Nhập môn React Native & Expo
- Cài đặt môi trường phát triển Expo CLI, chạy ứng dụng đầu tiên trên điện thoại (Expo Go) và hiểu sự khác biệt giữa DOM và Native Components.
- [Chi tiết bài học](lessons/week01.md)

## Tuần 2: Core Components & Styling
- Sử dụng View, Text, Image, ScrollView, TextInput. Áp dụng StyleSheet và Flexbox để bố cục giao diện linh hoạt (Responsive).
- [Chi tiết bài học](lessons/week02.md)

## Tuần 3: State & Props trong Mobile
- Quản lý trạng thái bằng useState, truyền dữ liệu bằng Props, vòng đời ứng dụng cơ bản.
- [Chi tiết bài học](lessons/week03.md)

## Tuần 4: Điều hướng (Navigation)
- Cài đặt React Navigation. Thiết lập Stack Navigator (chuyển trang) và Tab Navigator (thanh menu dưới đáy).
- [Chi tiết bài học](lessons/week04.md)

## Tuần 5: Làm việc với List & Dữ liệu lớn
- Tối ưu hóa hiệu năng danh sách dài với FlatList và SectionList. Tuỳ biến giao diện từng phần tử (List Item).
- [Chi tiết bài học](lessons/week05.md)

## Tuần 6: Kết nối API & Bất đồng bộ
- Sử dụng fetch/axios gọi RESTful API. Xử lý trạng thái Loading, hiển thị dữ liệu từ máy chủ và xử lý lỗi mạng.
- [Chi tiết bài học](lessons/week06.md)

## Tuần 7: Lưu trữ cục bộ (Local Storage)
- Lưu trạng thái offline bằng AsyncStorage. Lưu thông tin đăng nhập, điểm số hoặc cài đặt người dùng.
- [Chi tiết bài học](lessons/week07.md)

## Tuần 8: Sử dụng Native Modules
- Tích hợp thư viện truy cập phần cứng: Camera, Thư viện ảnh, GPS (Location) và cảm biến cơ bản.
- [Chi tiết bài học](lessons/week08.md)

## Tuần 9: Hoàn thiện Ứng dụng & UI/UX
- Thêm hiệu ứng Animation (Animated API). Làm đẹp giao diện với thư viện UI như React Native Paper hoặc NativeBase.
- [Chi tiết bài học](lessons/week09.md)

## Tuần 10: Đóng gói & Xuất bản Ứng dụng
- Tạo file APK/AAB cho Android và cấu hình build iOS. Chuẩn bị đưa ứng dụng lên Google Play và App Store.
- [Chi tiết bài học](lessons/week10.md)
