# Lịch Trình Chi Tiết 10 Tuần Back-End / 10-Week Back-End Schedule

---

## 🗓️ Lịch Trình Chi Tiết / Detailed Schedule

| Tuần / Week | Buổi / Session | Nội Dung Học / Topics | Hoạt Động Thực Hành / Labs & Tasks |
|-------------|----------------|-----------------------|-----------------------------------|
| **Tuần 1** | Buổi 1 | Tổng quan về Node.js Runtime & V8 Engine | Cài đặt Node.js và viết script chạy bằng node CLI |
| | Buổi 2 | Node.js Core Modules: File System (\`fs\`) & Path | Viết công cụ quản lý file log tự động bằng Python/JS |
| **Tuần 2** | Buổi 3 | Giao thức HTTP & Tạo máy chủ HTTP Server thô | Viết server HTTP trả về HTML thô không dùng framework |
| | Buổi 4 | Quản lý gói thư viện bằng npm và file package.json | Cài đặt các thư viện ngoài và tìm hiểu cơ chế node_modules |
| **Tuần 3** | Buổi 5 | Express.js Framework: Khởi tạo và Cấu trúc | Chuyển đổi HTTP Server thô sang dùng Express.js |
| | Buổi 6 | Định tuyến (Routing) & Lấy tham số (Request Parameters)| Viết các routes GET/POST xử lý tham số url và body |
| **Tuần 4** | Buổi 7 | Khái niệm Middleware trong Express.js | Viết custom middleware ghi lại thời gian request (Logger) |
| | Buổi 8 | Middleware bên thứ ba: CORS, Morgan, Body-Parser | Cấu hình bảo mật cors và định dạng dữ liệu đầu vào |
| **Tuần 5** | Buổi 9 | Kiến trúc RESTful API & Các phương thức HTTP | Thiết lập API CRUD đầy đủ cho đối tượng bài viết (Posts) |
| | Buổi 10 | Trình bày dữ liệu JSON & Xử lý mã trạng thái HTTP | Trả về JSON chuẩn với các mã trạng thái (200, 201, 400, 404, 500)|
| **Tuần 6** | Buổi 11 | Giới thiệu Cơ sở dữ liệu: SQL vs NoSQL | Phân tích ưu nhược điểm và cài đặt MongoDB Community |
| | Buổi 12 | Kết nối MongoDB thông qua Mongoose ORM | Tạo Schema và Model cho đối tượng Người dùng (User) |
| **Tuần 7** | Buổi 13 | Thực hiện các câu lệnh Query dữ liệu trên MongoDB | Viết API tìm kiếm, lọc và phân trang người dùng |
| | Buổi 14 | Mối quan hệ giữa các bảng (Relations) trong NoSQL | Tạo cấu trúc liên kết 1-N (Ví dụ: Một User viết nhiều Post)|
| **Tuần 8** | Buổi 15 | Bảo mật thông tin: Mã hóa mật khẩu với bcrypt | Viết tính năng Đăng ký người dùng và mã hóa mật khẩu |
| | Buổi 16 | Xác thực người dùng bằng JSON Web Token (JWT) | Tạo mã Token khi đăng nhập và viết middleware Auth Guard |
| **Tuần 9** | Buổi 17 | Giao tiếp thời gian thực: WebSockets & Socket.io | Viết máy chủ Chat Server realtime cơ bản |
| | Buổi 18 | Phòng chat (Rooms) và Phát sóng dữ liệu (Broadcast) | Xây dựng phòng chat riêng tư giữa các Client |
| **Tuần 10**| Buổi 19 | Quản lý biến môi trường với dotenv | Cấu hình ứng dụng chạy đa môi trường (Dev, Staging, Prod) |
| | Buổi 20 | Deploy ứng dụng Server lên Render / Render Cloud | Đưa máy chủ API trực tuyến và kết nối cơ sở dữ liệu cloud |

## 🎯 Checklist Sản Phẩm Đầu Ra / Weekly Deliverables

- [ ] **Tuần 1**: Script đọc ghi tệp tin bất đồng bộ hoạt động tốt.
- [ ] **Tuần 2**: Server HTTP trả về dữ liệu JSON mẫu khi truy cập.
- [ ] **Tuần 3**: Máy chủ Express có hệ thống routing phân cấp rõ ràng.
- [ ] **Tuần 4**: Ứng dụng tích hợp middleware tự động ghi log lỗi.
- [ ] **Tuần 5**: Bộ API RESTful CRUD hoàn chỉnh cho tài nguyên sản phẩm.
- [ ] **Tuần 6**: Kết nối thành công dự án Node.js tới MongoDB local.
- [ ] **Tuần 7**: API tìm kiếm và phân trang dữ liệu từ cơ sở dữ liệu thực.
- [ ] **Tuần 8**: Hệ thống đăng nhập/đăng ký người dùng lưu mật khẩu băm.
- [ ] **Tuần 9**: Server WebSocket phản hồi tin nhắn trong 50ms.
- [ ] **Tuần 10**: Địa chỉ API URL chạy chính thức kết nối database Atlas.
