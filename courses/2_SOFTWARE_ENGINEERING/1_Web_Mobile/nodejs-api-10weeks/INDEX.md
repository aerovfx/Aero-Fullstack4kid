# Khoá Học: Lập Trình Back-End Web Cơ Bản / Course: Web Back-End Development Foundations

Chào mừng bạn đến với khoá học **Lập trình Back-End với Node.js & Express (10 Tuần)**. Khoá học này được thiết kế để đào tạo học viên các kỹ năng lập trình phía máy chủ, xây dựng các cổng API RESTful, tương tác với cơ sở dữ liệu (MongoDB/SQL) và thiết lập hệ thống xác thực bảo mật chuẩn công nghiệp.

## 🛠️ Công Nghệ & Phần Mềm Sử Dụng / Software Stack

- **Ngôn ngữ**: JavaScript (Node.js).
- **Môi trường / Framework**: Express.js, Socket.io.
- **Cơ sở dữ liệu**: MongoDB / Mongoose, PostgreSQL / Prisma ORM.
- **Bảo mật**: JSON Web Token (JWT), bcrypt, helmet.
- **Công cụ Test API**: Postman / Thunder Client.
