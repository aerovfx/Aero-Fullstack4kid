# Khoá Học: Lập Trình Front-End Web Cơ Bản / Course: Web Front-End Development Foundations

Chào mừng bạn đến với khoá học **Lập trình Front-End Web (10 Tuần)**. Khoá học này được thiết kế để đào tạo học viên từ cơ bản về HTML/CSS cho tới các kỹ năng nâng cao về JavaScript ES6+ và phát triển ứng dụng Web tương tác bằng thư viện React.js.

## 🛠️ Công Nghệ & Phần Mềm Sử Dụng / Software Stack

- **Ngôn ngữ**: HTML5, CSS3, JavaScript (ES6+).
- **Thư viện / Framework**: React.js, Tailwind CSS.
- **Công cụ Build**: Vite, npm, node.js.
- **Trình soạn thảo**: Visual Studio Code (Extensions: Prettier, Live Server, ES7+ React/Redux snippets).
