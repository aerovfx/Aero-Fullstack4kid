# Lịch Trình Chi Tiết 10 Tuần Front-End / 10-Week Front-End Schedule

---

## 🗓️ Lịch Trình Chi Tiết / Detailed Schedule

| Tuần / Week | Buổi / Session | Nội Dung Học / Topics | Hoạt Động Thực Hành / Labs & Tasks |
|-------------|----------------|-----------------------|-----------------------------------|
| **Tuần 1** | Buổi 1 | Cú pháp cơ bản HTML5 & Các thẻ cấu trúc | Tạo trang blog cá nhân đơn giản bằng HTML |
| | Buổi 2 | CSS3 cơ bản: CSS Box Model & Màu sắc, Typography | Định dạng trang blog cá nhân đã tạo ở buổi 1 |
| **Tuần 2** | Buổi 3 | Flexbox Layout chuyên sâu | Dàn trang Header, Footer và Main content với Flexbox |
| | Buổi 4 | CSS Grid Layout chuyên sâu | Tạo trang trưng bày sản phẩm (Product Gallery) dùng Grid |
| **Tuần 3** | Buổi 5 | Thiết kế đáp ứng (Responsive Web Design) | Tạo giao diện tương thích cho cả Mobile và Desktop |
| | Buổi 6 | CSS Keyframes & Animations | Tạo các hiệu ứng chuyển động khi hover và loading spinners |
| **Tuần 4** | Buổi 7 | CSS Framework: Giới thiệu Tailwind CSS | Cài đặt Vite + Tailwind CSS và cấu hình dự án |
| | Buổi 8 | Thiết kế giao diện Dashboard bằng Tailwind CSS | Dựng giao diện quản trị Admin Dashboard trực quan |
| **Tuần 5** | Buổi 9 | JavaScript Cơ bản: Biến, Kiểu dữ liệu, Hàm | Viết các hàm tính toán cơ bản trên trình duyệt |
| | Buổi 10 | JS Array & Objects nâng cao | Xử lý danh sách dữ liệu người dùng ảo bằng JavaScript |
| **Tuần 6** | Buổi 11 | DOM Manipulation (Thao tác giao diện qua JS) | Viết ứng dụng To-Do List thêm sửa xóa công việc |
| | Buổi 12 | JS Events & LocalStorage | Lưu danh sách việc cần làm vào bộ nhớ trình duyệt |
| **Tuần 7** | Buổi 13 | JavaScript ES6+ nâng cao (Destructuring, Arrow Function) | Refactor mã nguồn To-Do List sang phong cách ES6 |
| | Buổi 14 | Lập trình bất đồng bộ: Promises & Async/Await | Tìm hiểu cơ chế Event Loop và xử lý bất đồng bộ |
| **Tuần 8** | Buổi 15 | Kết nối API: Fetch API & Axios | Lấy dữ liệu thời tiết thực tế từ OpenWeather API và hiển thị |
| | Buổi 16 | Xử lý lỗi API & Loading state | Hiển thị màn hình chờ (Skeleton loading) khi gọi API |
| **Tuần 9** | Buổi 17 | Giới thiệu React.js & Cấu trúc thư mục Vite | Khởi tạo dự án React và tạo các Component cơ bản |
| | Buổi 18 | React Hooks: useState & useEffect | Viết ứng dụng đếm số và gọi API lấy danh sách bài đăng |
| **Tuần 10**| Buổi 19 | Quản lý Form trong React & Props truyền dữ liệu | Tạo form đăng ký đăng nhập có kiểm tra lỗi (validation) |
| | Buổi 20 | Đóng gói & Deploy ứng dụng Front-End lên Netlify | Build dự án sản phẩm và đưa trang web lên Internet |

## 🎯 Checklist Sản Phẩm Đầu Ra / Weekly Deliverables

- [ ] **Tuần 1**: Trang blog HTML đơn giản có style CSS cơ bản.
- [ ] **Tuần 2**: Trang bộ sưu tập ảnh (Image Gallery) có layout responsive.
- [ ] **Tuần 3**: Trang web portfolio cá nhân có hiệu ứng chuyển động mượt mà.
- [ ] **Tuần 4**: Landing Page hoàn chỉnh viết bằng Tailwind CSS.
- [ ] **Tuần 5**: Các bài tập thuật toán JS cơ bản chạy trên console.
- [ ] **Tuần 6**: Ứng dụng To-Do List lưu được công việc sau khi reload trang.
- [ ] **Tuần 7**: Script JS bất đồng bộ gọi dữ liệu thành công.
- [ ] **Tuần 8**: Trang web thời tiết lấy dữ liệu từ OpenWeather API trực tuyến.
- [ ] **Tuần 9**: Ứng dụng React cơ bản chia thành các component tái sử dụng.
- [ ] **Tuần 10**: Link deploy website sản phẩm cuối khoá công khai trên Netlify/Vercel.
