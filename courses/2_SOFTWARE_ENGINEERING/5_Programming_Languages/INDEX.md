# Ngôn ngữ lập trình hiện đại

Ba lộ trình 10 tuần giúp học viên hiểu cách các ngôn ngữ phổ biến giải quyết cùng một bài toán theo những triết lý khác nhau.

| Lộ trình | Phù hợp với | Điểm mạnh | Đồ án |
|---|---|---|---|
| [Rust Fundamentals](rust-fundamentals-10weeks/INDEX.md) | Hệ thống an toàn, backend hiệu năng cao | Memory safety không cần garbage collector | Task CLI |
| [Modern C++](cpp-modern-10weeks/INDEX.md) | Game, đồ họa, nhúng, hệ thống | Kiểm soát tài nguyên và hiệu năng | Inventory CLI |
| [Modern C#/.NET](csharp-dotnet-10weeks/INDEX.md) | Backend, desktop, Unity | Hệ sinh thái .NET và năng suất phát triển | Task Web API |

## Thứ tự học đề xuất

Người mới nên biết biến, điều kiện, vòng lặp và hàm trước khi bắt đầu. Không cần học cả ba khóa cùng lúc:

- Chọn **C++** nếu muốn theo game engine, đồ họa, robotics hoặc embedded.
- Chọn **C#** nếu muốn làm .NET backend, ứng dụng doanh nghiệp hoặc Unity.
- Chọn **Rust** nếu muốn xây phần mềm hệ thống hoặc dịch vụ cần đồng thời cao và an toàn bộ nhớ.

## Chuẩn chất lượng chung

Mỗi bài thực hành phải biên dịch không cảnh báo, có tên biến rõ ràng, xử lý đầu vào lỗi và có ít nhất một kiểm thử tự động. Đồ án cuối khóa phải có README, hướng dẫn chạy và mô tả các quyết định kỹ thuật.
