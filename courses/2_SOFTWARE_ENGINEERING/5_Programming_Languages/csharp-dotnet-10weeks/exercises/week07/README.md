# Bài tập tuần 7: Async/await

Hoàn thiện `starter.cs` thành chương trình nhỏ minh họa chủ đề tuần. Chương trình phải xử lý ba trường hợp: dữ liệu đúng, giá trị biên và dữ liệu sai.

## Yêu cầu

- Không thay đổi tên file starter.
- Thêm ít nhất 3 kiểm thử hoặc assertion.
- Không bỏ qua lỗi và không tắt compiler warning.
- Viết chú thích tiếng Việt cho quyết định chưa hiển nhiên.

## Chấm điểm

Đúng chức năng 50%; xử lý lỗi/biên 25%; code rõ và kiểm thử 25%.
