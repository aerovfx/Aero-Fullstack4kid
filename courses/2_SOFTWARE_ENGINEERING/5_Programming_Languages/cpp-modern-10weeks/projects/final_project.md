# Dự án cuối khóa

Xây sản phẩm theo đúng định hướng trong INDEX: có chức năng thêm, sửa trạng thái, liệt kê, tìm kiếm và lưu dữ liệu. Tách domain logic khỏi nhập/xuất để kiểm thử độc lập.

## Bắt buộc

- README hướng dẫn build/run và mô tả kiến trúc.
- Tối thiểu 8 kiểm thử gồm happy path, biên và lỗi.
- Build không warning với chế độ nghiêm ngặt.
- Không commit binary, cache, secret hoặc dữ liệu cá nhân.

## Mốc

Tuần 7 chốt phạm vi; tuần 8 thiết kế và test plan; tuần 9 MVP; tuần 10 hoàn thiện, demo và phản biện.
