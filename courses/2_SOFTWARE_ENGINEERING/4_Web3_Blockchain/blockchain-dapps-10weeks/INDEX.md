# Web3 & Blockchain với Solidity — 10 tuần

Khóa học dẫn từ nền tảng blockchain/EVM đến token, kiểm thử bảo mật và tích hợp DApp. Code mẫu dùng JavaScript thuần để minh họa logic cốt lõi và chạy được ngay; bài học hướng dẫn chuyển cùng tư duy sang Solidity/Hardhat.

## Cấu trúc

- [Lịch học](schedule.md)
- `lessons/week01.md` … `week10.md`: lý thuyết và lab.
- `code/week01.js` … `week10.js`: code mẫu chạy độc lập.
- `exercises/week01` … `week10`: đề bài và starter cho học viên.
- [Dự án cuối khóa](projects/final_project.md)

## Chạy code mẫu

Yêu cầu Node.js 18 trở lên:

```bash
node code/week01.js
```

## Nguyên tắc an toàn

Chỉ dùng localnet/testnet. Không ghi private key, seed phrase hoặc token thật vào mã nguồn; luôn kiểm tra network và nội dung giao dịch trước khi ký.
