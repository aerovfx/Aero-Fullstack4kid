# Bài tập tuần 6: Kế thừa và thư viện

## Yêu cầu

Tính phí theo basis point và không làm thay đổi đầu vào.

- Không sửa tên hàm `feeOf(amount, bps)`.
- Tự thêm ít nhất 3 ca kiểm thử: thành công, biên và lỗi.
- Không dùng khóa thật, seed phrase hoặc tiền thật.

## Chạy

```bash
node starter.js
```

## Tiêu chí hoàn thành

Đúng chức năng (50%), xử lý lỗi (25%), mã dễ đọc và chú thích rõ (25%).
