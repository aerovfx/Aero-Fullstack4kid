# Bài tập tuần 7: ERC-20

## Yêu cầu

Cài đặt transfer và bảo toàn tổng cung.

- Không sửa tên hàm `transferToken(state, from, to, amount)`.
- Tự thêm ít nhất 3 ca kiểm thử: thành công, biên và lỗi.
- Không dùng khóa thật, seed phrase hoặc tiền thật.

## Chạy

```bash
node starter.js
```

## Tiêu chí hoàn thành

Đúng chức năng (50%), xử lý lỗi (25%), mã dễ đọc và chú thích rõ (25%).
