# Bài tập tuần 2: Solidity và trạng thái hợp đồng

## Yêu cầu

Hoàn thiện hàm tăng bộ đếm, từ chối số âm.

- Không sửa tên hàm `increment(state, amount)`.
- Tự thêm ít nhất 3 ca kiểm thử: thành công, biên và lỗi.
- Không dùng khóa thật, seed phrase hoặc tiền thật.

## Chạy

```bash
node starter.js
```

## Tiêu chí hoàn thành

Đúng chức năng (50%), xử lý lỗi (25%), mã dễ đọc và chú thích rõ (25%).
