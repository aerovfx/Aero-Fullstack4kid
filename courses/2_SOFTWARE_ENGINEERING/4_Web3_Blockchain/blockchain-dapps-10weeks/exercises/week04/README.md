# Bài tập tuần 4: Array, struct và mapping

## Yêu cầu

Thêm người dùng duy nhất vào mapping theo địa chỉ.

- Không sửa tên hàm `addUser(users, address, name)`.
- Tự thêm ít nhất 3 ca kiểm thử: thành công, biên và lỗi.
- Không dùng khóa thật, seed phrase hoặc tiền thật.

## Chạy

```bash
node starter.js
```

## Tiêu chí hoàn thành

Đúng chức năng (50%), xử lý lỗi (25%), mã dễ đọc và chú thích rõ (25%).
