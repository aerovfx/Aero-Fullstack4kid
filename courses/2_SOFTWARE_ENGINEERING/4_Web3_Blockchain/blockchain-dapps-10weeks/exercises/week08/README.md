# Bài tập tuần 8: ERC-721 NFT

## Yêu cầu

Mint tokenId duy nhất và lưu chủ sở hữu.

- Không sửa tên hàm `mintNft(owners, tokenId, owner)`.
- Tự thêm ít nhất 3 ca kiểm thử: thành công, biên và lỗi.
- Không dùng khóa thật, seed phrase hoặc tiền thật.

## Chạy

```bash
node starter.js
```

## Tiêu chí hoàn thành

Đúng chức năng (50%), xử lý lỗi (25%), mã dễ đọc và chú thích rõ (25%).
