# Bài tập tuần 10: Tích hợp DApp

## Yêu cầu

Chuẩn hóa lỗi RPC và trả trạng thái giao dịch dễ hiển thị.

- Không sửa tên hàm `transactionStatus(receipt)`.
- Tự thêm ít nhất 3 ca kiểm thử: thành công, biên và lỗi.
- Không dùng khóa thật, seed phrase hoặc tiền thật.

## Chạy

```bash
node starter.js
```

## Tiêu chí hoàn thành

Đúng chức năng (50%), xử lý lỗi (25%), mã dễ đọc và chú thích rõ (25%).
