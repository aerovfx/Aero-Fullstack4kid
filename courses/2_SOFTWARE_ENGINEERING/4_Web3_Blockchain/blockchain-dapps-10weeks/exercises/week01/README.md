# Bài tập tuần 1: Chuỗi khối và EVM

## Yêu cầu

Hoàn thiện `mineBlock`: tạo hash SHA-256 bắt đầu bằng `00`.

- Không sửa tên hàm `mineBlock(data, previousHash)`.
- Tự thêm ít nhất 3 ca kiểm thử: thành công, biên và lỗi.
- Không dùng khóa thật, seed phrase hoặc tiền thật.

## Chạy

```bash
node starter.js
```

## Tiêu chí hoàn thành

Đúng chức năng (50%), xử lý lỗi (25%), mã dễ đọc và chú thích rõ (25%).
