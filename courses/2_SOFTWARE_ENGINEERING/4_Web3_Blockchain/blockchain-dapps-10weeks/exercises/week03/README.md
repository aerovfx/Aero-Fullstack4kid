# Bài tập tuần 3: Kiểu dữ liệu và visibility

## Yêu cầu

Kiểm tra địa chỉ EVM gồm `0x` và 40 ký tự hex.

- Không sửa tên hàm `isAddress(value)`.
- Tự thêm ít nhất 3 ca kiểm thử: thành công, biên và lỗi.
- Không dùng khóa thật, seed phrase hoặc tiền thật.

## Chạy

```bash
node starter.js
```

## Tiêu chí hoàn thành

Đúng chức năng (50%), xử lý lỗi (25%), mã dễ đọc và chú thích rõ (25%).
