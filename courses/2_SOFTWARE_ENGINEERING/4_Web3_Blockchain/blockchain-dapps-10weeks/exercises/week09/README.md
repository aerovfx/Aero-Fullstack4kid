# Bài tập tuần 9: Kiểm thử và bảo mật

## Yêu cầu

Phát hiện lời gọi lặp lại bằng khóa chống reentrancy.

- Không sửa tên hàm `withGuard(state, action)`.
- Tự thêm ít nhất 3 ca kiểm thử: thành công, biên và lỗi.
- Không dùng khóa thật, seed phrase hoặc tiền thật.

## Chạy

```bash
node starter.js
```

## Tiêu chí hoàn thành

Đúng chức năng (50%), xử lý lỗi (25%), mã dễ đọc và chú thích rõ (25%).
