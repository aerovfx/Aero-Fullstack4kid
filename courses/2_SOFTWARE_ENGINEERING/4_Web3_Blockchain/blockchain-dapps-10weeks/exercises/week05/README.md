# Bài tập tuần 5: Lỗi và gas

## Yêu cầu

Viết chuyển token có kiểm tra số dư, không lặp toàn bộ tài khoản.

- Không sửa tên hàm `transfer(balances, from, to, amount)`.
- Tự thêm ít nhất 3 ca kiểm thử: thành công, biên và lỗi.
- Không dùng khóa thật, seed phrase hoặc tiền thật.

## Chạy

```bash
node starter.js
```

## Tiêu chí hoàn thành

Đúng chức năng (50%), xử lý lỗi (25%), mã dễ đọc và chú thích rõ (25%).
