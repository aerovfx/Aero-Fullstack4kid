# Khoá Học: Lập Trình Rust Web3 Solana Smart Contracts / Course: Rust Web3 Smart Contracts (Solidity vs Solana)

Chào mừng bạn đến với khoá học **Lập trình Rust Web3 & Solana Smart Contracts (10 Tuần)**. Khoá học này được thiết kế để dẫn dắt học viên từ các khái niệm cơ bản về kiến trúc Solana, mô hình tài khoản (Account Model) cho tới việc sử dụng Anchor Framework để phát triển, kiểm thử và triển khai các chương trình hợp đồng thông minh (Programs) hiệu năng cao bằng Rust.

## 🛠️ Công Nghệ & Phần Mềm Sử Dụng / Software Stack

- **Ngôn ngữ**: Rust, TypeScript.
- **Blockchain Framework**: Anchor Framework (v0.29+).
- **SDK**: Solana Web3.js, @coral-xyz/anchor.
- **Môi trường Test**: Solana Local Validator, mocha/chai.
- **Ví điện tử**: Phantom / Backpack (Solana Devnet).
