|---:|---|---|
| 1 | Solana, SVM và xử lý song song | Phân tích read/write set của giao dịch |
| 2 | Account model, owner, signer, writable | Hàm validation quyền account |
| 3 | Anchor workspace, Context và constraint | Mô phỏng kiểm tra Context |
| 4 | Native Rust program và instruction | Giải mã instruction, cập nhật an toàn |
| 5 | Cấu trúc program Anchor và error | Tách state, instruction và lỗi nghiệp vụ |
