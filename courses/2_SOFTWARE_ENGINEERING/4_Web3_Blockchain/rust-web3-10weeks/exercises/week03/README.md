# Bài tập tuần 3: Anchor cơ bản

## Yêu cầu

Mô hình hóa Context và kiểm tra các constraint trước khi xử lý.

- Hoàn thiện `starter.rs` mà không dùng `unwrap()` trên dữ liệu người dùng.
- Tự viết ít nhất 3 ca kiểm thử: thành công, biên và lỗi.
- Giải thích ngắn account nào đọc, account nào ghi và ai phải ký.

## Chạy

```bash
rustc starter.rs -o /tmp/rust-web3-exercise && /tmp/rust-web3-exercise
```

## Tiêu chí hoàn thành

Đúng chức năng (50%), an toàn kiểu/lỗi (25%), mã dễ đọc và chú thích rõ (25%).
