# Lộ trình Quản Trị Hệ Thống (System Administration) (10 Tuần)

## Tuần 1: Nhập môn Máy chủ & Hệ điều hành Linux/Windows
- Sự khác biệt giữa Desktop và Server. Cài đặt Ubuntu Server và Windows Server. Khái niệm về CLI (Command Line Interface).
- [Chi tiết bài học](lessons/week01.md)

## Tuần 2: Quản lý File System, Người dùng và Phân quyền
- Cấu trúc thư mục Linux. Tạo User/Group. Phân quyền rwx (Read/Write/Execute) và chmod/chown.
- [Chi tiết bài học](lessons/week02.md)

## Tuần 3: Tự động hóa với Shell Scripting
- Cơ bản về Bash Script trên Linux và PowerShell trên Windows. Viết kịch bản tự động sao lưu dữ liệu và dọn dẹp log.
- [Chi tiết bài học](lessons/week03.md)

## Tuần 4: Quản lý Tiến trình và Tài nguyên
- Theo dõi hiệu suất máy chủ. Sử dụng top, htop, ps. Quản lý systemd services (start, stop, enable, restart).
- [Chi tiết bài học](lessons/week04.md)

## Tuần 5: Cấu hình Dịch vụ mạng cơ bản (SSH, DNS, DHCP)
- Bảo mật truy cập từ xa với SSH Key. Thiết lập máy chủ phân giải tên miền nội bộ (Local DNS).
- [Chi tiết bài học](lessons/week05.md)

## Tuần 6: Triển khai Web Server & Database Server
- Cài đặt và cấu hình Nginx/Apache. Cài đặt MySQL/PostgreSQL. Triển khai kiến trúc LAMP/LEMP stack.
- [Chi tiết bài học](lessons/week06.md)

## Tuần 7: Windows Server & Active Directory (AD)
- Thiết lập Domain Controller. Quản lý tài nguyên, Group Policy (GPO) trong mạng nội bộ doanh nghiệp.
- [Chi tiết bài học](lessons/week07.md)

## Tuần 8: Giám sát hệ thống (System Monitoring)
- Cài đặt Prometheus và Grafana để theo dõi sức khoẻ của hàng chục máy chủ qua biểu đồ trực quan thời gian thực.
- [Chi tiết bài học](lessons/week08.md)

## Tuần 9: Sao lưu dữ liệu (Backup) & Phục hồi (Recovery)
- Chiến lược backup 3-2-1. Lập lịch tự động rsync/cronjob. Diễn tập phục hồi sau sự cố hỏng ổ cứng.
- [Chi tiết bài học](lessons/week09.md)

## Tuần 10: Bảo mật máy chủ (Hardening) & Đồ án
- Cấu hình tường lửa UFW/iptables. Chống tấn công Brute-force bằng Fail2ban. Cập nhật bản vá bảo mật.
- [Chi tiết bài học](lessons/week10.md)
