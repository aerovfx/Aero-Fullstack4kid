# Quản trị hệ thống — 10 tuần

Lộ trình thực hành Linux/Windows Server từ vận hành nền tảng đến dịch vụ, giám sát, backup và hardening.

## Cấu trúc

- [Lịch học](schedule.md)
- `lessons/week01.md` … `week10.md`: bài học.
- `code/week01.*` … `week10.*`: script mẫu ưu tiên audit/dry-run.
- `exercises/week01/` … `week10/`: starter và yêu cầu kiểm thử.
- [Dự án cuối khóa](projects/final_project.md)

Quy trình mỗi tuần: đọc lesson, chạy code trong VM lab, hoàn thiện exercise, ghi log kiểm thử và chuẩn bị rollback. Không chạy script thay đổi trạng thái trên production khi chưa review, backup và phê duyệt.
