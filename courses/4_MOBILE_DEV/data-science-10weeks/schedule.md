## 🗓️ Lịch Trình Chi Tiết / Detailed Schedule

| Tuần / Week | Buổi / Session | Nội Dung Học / Topics | Hoạt Động Thực Hành / Labs & Tasks |
|-------------|----------------|-----------------------|-----------------------------------|
| **Tuần 1** | Buổi 1 | Giới thiệu Khoa học Dữ liệu & Quy trình CRISP-DM | Cài đặt Anaconda và tạo Notebook đầu tiên trên Jupyter |
| | Buổi 2 | Python nâng cao cho Xử lý Dữ liệu (List Comprehension)| Viết các hàm lambda, map, filter xử lý chuỗi dữ liệu |
| **Tuần 2** | Buổi 3 | Thư viện NumPy: Khởi tạo mảng & Các kiểu dữ liệu | Tạo mảng 1D, 2D và kiểm tra thuộc tính shape, dtype |
| | Buổi 4 | Các phép toán số học & Vector hóa (Vectorization) | Tính toán nhân ma trận và xử lý mảng không dùng vòng lặp |
| **Tuần 3** | Buổi 5 | Cắt lát mảng (Slicing) & Lọc điều kiện (Boolean Indexing)| Trích xuất dữ liệu con và lọc phần tử lớn hơn trung bình |
| | Buổi 6 | Các hàm thống kê cơ bản: Mean, Median, Std, Sum | Tính điểm trung bình và độ lệch chuẩn của tập điểm số |
| **Tuần 4** | Buổi 7 | Giới thiệu Pandas: Cấu trúc Series & DataFrame | Tạo DataFrame từ các cấu trúc List và Dictionary |
| | Buổi 8 | Đọc và ghi dữ liệu: CSV, Excel, SQL, JSON | Đọc file dữ liệu bán hàng CSV và xuất báo cáo ra Excel |
| **Tuần 5** | Buổi 9 | Chọn dữ liệu bằng loc, iloc & Lọc dữ liệu phức tạp | Trích xuất cột, dòng cụ thể theo nhãn hoặc chỉ số |
| | Buổi 10 | Gom nhóm dữ liệu (GroupBy) & Các hàm tổng hợp | Tính tổng doanh thu theo từng danh mục sản phẩm |
| **Tuần 6** | Buổi 11 | Xử lý dữ liệu bị khuyết (Missing Data) | Tìm giá trị rỗng (NaN) và điền khuyết bằng mean/median |
| | Buổi 12 | Xử lý dữ liệu trùng lặp & Chuẩn hóa kiểu dữ liệu | Loại bỏ các dòng trùng lặp và định dạng lại cột ngày tháng |
| **Tuần 7** | Buổi 13 | Ghép nối dữ liệu: Concatenate & Merge | Kết nối bảng thông tin Khách hàng với bảng Đơn hàng |
| | Buổi 14 | Biến đổi dữ liệu: Apply & Map | Tạo cột mới xếp loại khách hàng dựa trên tổng chi tiêu |
| **Tuần 8** | Buổi 15 | Trực quan hóa dữ liệu bằng Matplotlib | Vẽ biểu đồ đường (Line plot) và biểu đồ cột (Bar chart) |
| | Buổi 16 | Trực quan hóa dữ liệu nâng cao bằng Seaborn | Vẽ biểu đồ phân bố (Distplot), tương quan (Heatmap) |
| **Tuần 9** | Buổi 17 | Phân tích Khám phá Dữ liệu (EDA) | Phân tích tập dữ liệu Titanic tìm các đặc trưng ảnh hưởng |
| | Buổi 18 | Giới thiệu Học máy (Machine Learning) & Scikit-Learn | Chia tập dữ liệu thành Train/Test và chuẩn bị scaler |
| **Tuần 10**| Buổi 19 | Mô hình Hồi quy Tuyến tính (Linear Regression) | Huấn luyện mô hình dự đoán giá nhà dựa trên diện tích |
| | Buổi 20 | Đánh giá mô hình học máy: MSE, R-squared | Tính toán các chỉ số sai số và vẽ đường hồi quy dự đoán |
