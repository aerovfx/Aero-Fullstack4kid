# Tuần 3: Cây quyết định & Rừng ngẫu nhiên (Decision Trees & Random Forests)

## 3. Mã nguồn thực hành (Hands-on Code)
- Các Jupyter Notebooks mẫu trình bày từng bước tiền xử lý, huấn luyện và đánh giá mô hình.

## 4. Bài tập (Challenge)
