# Bài tập tuần 6: Dodge và stamina

Hoàn thiện `starter.cpp` và tích hợp vào prototype hoặc project engine của tuần.

## Yêu cầu

- Có ít nhất 3 kiểm thử: happy path, giá trị biên và lỗi.
- Tách logic nghiệp vụ khỏi UI/engine API khi có thể.
- Ghi chú tiếng Việt cho state, input, output và invariant.
- UI phải dùng được bằng bàn phím; game phải có trạng thái thắng/thua và cách reset rõ.

## Chấm điểm

Chức năng 40%; trải nghiệm/game feel 20%; kiểm thử 20%; accessibility/hiệu năng 10%; tài liệu 10%.
