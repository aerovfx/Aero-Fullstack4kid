# Lộ trình Lập Trình Game: Unity 2D & C# (10 Tuần)

## Tuần 1: Nhập môn Game Dev & Unity Engine
- Cài đặt Unity Hub, Editor. Làm quen giao diện Scene, Game, Hierarchy, Inspector. Khái niệm GameObject và Component.
- [Chi tiết bài học](lessons/week01.md)

## Tuần 2: Cơ bản về C# trong Unity
- Tạo script C#. Biến, Kiểu dữ liệu, Câu lệnh điều kiện (if/else), Vòng lặp. Khai báo biến hiển thị trên Inspector (SerializeField).
- [Chi tiết bài học](lessons/week02.md)

## Tuần 3: Điều khiển nhân vật 2D
- Transform.Translate, lấy Input từ bàn phím (Input.GetAxis). Code di chuyển nhân vật sang trái/phải, nhảy (Jump).
- [Chi tiết bài học](lessons/week03.md)

## Tuần 4: Hệ thống Vật lý (Physics 2D)
- Gắn Rigidbody2D và Collider2D. Xử lý trọng lực, va chạm (OnCollisionEnter2D, OnTriggerEnter2D). Tránh lỗi xuyên tường.
- [Chi tiết bài học](lessons/week04.md)

## Tuần 5: Animation 2D & Sprite
- Cắt Sprite Sheet. Tạo Animation Clip (Idle, Run, Jump). Sử dụng Animator Controller và thiết lập Parameters chuyển đổi trạng thái.
- [Chi tiết bài học](lessons/week05.md)

## Tuần 6: Tạo môi trường (Tilemap) & Camera
- Xây dựng màn chơi bằng Tilemap/Grid. Cấu hình Cinemachine để Camera tự động bám theo nhân vật chính.
- [Chi tiết bài học](lessons/week06.md)

## Tuần 7: Giao diện Người dùng (UI)
- Canvas, Text, Button, Image. Tạo màn hình Menu chính (Main Menu), hiển thị Điểm số (Score), và màn hình Game Over.
- [Chi tiết bài học](lessons/week07.md)

## Tuần 8: Quản lý Màn chơi (Scene Management)
- Chuyển cảnh giữa Menu và Game bằng SceneManager. Load/Reload màn chơi, xử lý trạng thái tạm dừng (Pause).
- [Chi tiết bài học](lessons/week08.md)

## Tuần 9: Âm thanh (Audio) & Hiệu ứng hạt (Particle)
- Gắn AudioSource phát nhạc nền và hiệu ứng (SFX). Tạo Particle System cho hiệu ứng cháy nổ, ăn tiền.
- [Chi tiết bài học](lessons/week09.md)

## Tuần 10: Tối ưu hóa & Xuất Game (Build)
- Khái niệm Prefab, Object Pooling (tối ưu đạn bắn). Build game ra file .exe (Windows), WebGL (chơi trên trình duyệt) hoặc Android APK.
- [Chi tiết bài học](lessons/week10.md)
