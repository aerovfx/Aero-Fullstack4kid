# Bài tập tuần 2: Recon có ủy quyền

Hoàn thiện `starter.py` trên dữ liệu giả hoặc hệ thống lab thuộc quyền kiểm soát. Nộp scope/Rules of Engagement trước khi thực hành.

## Yêu cầu

- Mặc định offline, read-only hoặc dry-run.
- Có ít nhất 3 kiểm thử: hợp lệ, biên và dữ liệu độc hại/sai.
- Bằng chứng phải che IP, username, token và dữ liệu cá nhân.
- Kèm đề xuất phòng thủ, cách rollback và giới hạn của kết quả.

## Chấm điểm

Đúng chức năng 35%; an toàn/pháp lý 30%; kiểm thử 20%; báo cáo 15%.
