## TIẾT 1: CÁC LOẠI TAM GIÁC (45 phút)

### I. MỤC ĐÍCH
- Nhận biết tam giác đều, cân, vuông, tù, nhọn
- Phân loại theo cạnh và góc

### II. CHUẨN BỊ
| Đồ dùng | Chi tiết |
|----------|----------|
| **Giáo viên** | Máy chiếu, GeoGebra, thước, compa |
| **Học sinh** | Thước, compa, giấy |
| **Phần mềm** | GeoGebra Geometry |

### III. CÁC HOẠT ĐỘNG DẠY HỌC

#### **Hoạt động 1: Khởi động (5 phút)**

**GV:** "Em thấy hình tam giác ở đâu trong cuộc sống?"

**Hình minh họa:** Mái nhà, biển báo, tam giác thước

---

#### **Hoạt động 2: Trình bày kiến thức mới (15 phút)**

**Bước 1: Định nghĩa tam giác**
- Tam giác là hình gồm 3 cạnh, 3 đỉnh, 3 góc

**Bước 2: Phân loại theo cạnh**

| Loại | Đặc điểm | Ký hiệu |
|------|-----------|---------|
| Tam giác đều | 3 cạnh bằng nhau | a = b = c |
| Tam giác cân | 2 cạnh bằng nhau | a = b ≠ c |
| Tam giác thường | 3 cạnh khác nhau | a ≠ b ≠ c |

**Bước 3: Phân loại theo góc**

| Loại | Đặc điểm | Góc |
|------|-----------|-----|
| Tam giác vuông | Có 1 góc 90° | α = 90° |
| Tam giác tù | Có 1 góc > 90° | α > 90° |
| Tam giác nhọn | 3 góc < 90° | α, β, γ < 90° |

---

#### **Hoạt động 3: Mô phỏng GeoGebra (15 phút)**

**Hướng dẫn giáo viên:**

**Vẽ tam giác đều:**
1. Mở GeoGebra Geometry
2. Vẽ đoạn thẳng AB = 5cm
3. Từ A, vẽ cung tròn bán kính 5cm
4. Từ B, vẽ cung tròn bán kính 5cm
5. Giao điểm C → Tam giác ABC đều

**Vẽ tam giác vuông:**
1. Vẽ đoạn thẳng AB = 4cm
2. Từ B, kẻ góc vuông
3. Trên tia góc vuông, lấy BC = 3cm
4. Nối AC → Tam giác ABC vuông tại B

**Học sinh thực hành:**
- Vẽ 3 loại tam giác trên GeoGebra
- Đo góc, cạnh để kiểm tra

---

**Bài 2:** Vẽ tam giác trên giấy:

## TIẾT 2: TÍNH CHẤT TAM GIÁC (45 phút)

### I. MỤC ĐÍCH
- Tổng 3 góc tam giác = 180°
- Quan hệ giữa cạnh và góc đối diện

### II. CÁC HOẠT ĐỘNG DẠY HỌC

#### **Hoạt động 2: Tr trình bày (15 phút)**

**Tính chất quan trọng:**
```
Tổng 3 góc trong tam giác = 180°
α + β + γ = 180°
```

**Ví dụ:** Tam giác ABC có α = 60°, β = 70°. Tìm γ?
```
γ = 180° - 60° - 70° = 50°
```

**Quan hệ cạnh-góc:**
- Cạnh lớn nhất đối diện góc lớn nhất
- Cạnh nhỏ nhất đối diện góc nhỏ nhất

## TIẾT 3: CÁC LOẠI TỨ GIÁC (45 phút)

### I. MỤC ĐÍCH
- Nhận biết hình bình hành, hình chữ nhật, hình vuông, hình thang
- Phân loại theo cạnh và góc

### II. CÁC HOẠT ĐỘNG DẠY HỌC

#### **Hoạt động 2: Tr trình bày (15 phút)**

**Phân loại tứ giác:**

| Hình | Đặc điểm | Quan hệ |
|------|-----------|---------|
| **Hình bình hành** | 2 cặp cạnh đối song song | a//c, b//d |
| **Hình chữ nhật** | HB + 4 góc vuông | α = β = γ = δ = 90° |
| **Hình vuông** | HC + 4 cạnh bằng nhau | a = b = c = d, α = 90° |
| **Hình thang** | 1 cặp cạnh đối song song | a//c, b∦d |

**Sơ đồ quan hệ:**
```
        Tứ giác
           │
    ┌──────┴──────┐
    │              │
Hình thang    Hình bình hành
                   │
            ┌──────┴──────┐
            │              │
       Hình chữ nhật   Hình bình hành
            │          không phải CN
       ┌────┴────┐
       │         │
   Hình vuông  Hình chữ nhật
              không phải HN
```

## TIẾT 4: HÌNH TRÒN (45 phút)

### I. MỤC ĐÍCH
- Nhận biết tâm, bán kính, đường kính
- Mối quan hệ: d = 2r

### II. CÁC HOẠT ĐỘNG DẠY HỌC

#### **Hoạt động 2: Tr trình bày (15 phút)**

**Các yếu tố hình tròn:**
| Yêu tố | Ký hiệu | Mô tả |
|---------|---------|-------|
| Tâm | O | Điểm chính giữa |
| Bán kính | r | Từ tâm đến đường tròn |
| Đường kính | d | Qua tâm, nối 2 điểm đường tròn |

**Mối quan hệ:**
```
d = 2r
r = d/2
```

## TIẾT 5: CHU VI TAM GIÁC VÀ TỨ GIÁC (45 phút)

### I. MỤC ĐÍCH
- Tính chu vi tam giác, tứ giác

### II. CÁC HOẠT ĐỘNG DẠY HỌC

#### **Hoạt động 2: Tr trình bày (15 phút)**

**Chu vi tam giác:**
```
P = a + b + c
```
- P: Chu vi
- a, b, c: Độ dài 3 cạnh

**Chu vi tứ giác:**
```
P = a + b + c + d
```

## TIẾT 6: DIỆN TÍCH TAM GIÁC (45 phút)

### I. MỤC ĐÍCH
- Tính diện tích tam giác

### II. CÁC HOẠT ĐỘNG DẠY HỌC

#### **Hoạt động 2: Tr trình bày (15 phút)**

**Công thức:**
```
S = (a × h) / 2
```
- S: Diện tích
- a: Cạnh đáy
- h: Chiều cao tương ứng

**Ví dụ:** Tam giác có cạnh đáy 8cm, chiều cao 5cm
```
S = (8 × 5) / 2 = 20 cm²
```

## TIẾT 7: DIỆN TÍCH TỨ GIÁC (45 phút)

### I. MỤC ĐÍCH
- Tính diện tích hình bình hành, hình chữ nhật, hình vuông, hình thang

### II. CÁC HOẠT ĐỘNG DẠY HỌC

#### **Hoạt động 2: Tr trình bày (15 phút)**

**Công thức:**

| Hình | Công thức | Ký hiệu |
|------|-----------|---------|
| Hình chữ nhật | S = a × b | a, b: cạnh |
| Hình vuông | S = a² | a: cạnh |
| Hình bình hành | S = a × h | a: cạnh đáy, h: chiều cao |
| Hình thang | S = (a + c) × h / 2 | a, c: đáy, h: chiều cao |

C = 2 × π × r

### GeoGebra - Lệnh thường dùng
| Lệnh | Mô tả |
|------|-------|
| `Circle((0,0), 5)` | Vẽ hình tròn tâm O, r=5 |
